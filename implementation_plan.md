# Shorten Photopea Editor URLs in Workflows

The long Photopea editor URL generated by the `all images url builder` node in our n8n workflows (`Overhead-North`, `Overhead-Only`, `Full`) contains a complete embedded configuration payload. This makes the URL extremely large, leading to errors and exceeding limits when posted via the `ntfy.sh` messaging service or stored in SureCart notes. 

We will integrate the Cloudflare-based **Sink link shortener** (`https://link.brokertricks.com`) to shorten this URL inline before passing it to SureCart, `ntfy.sh`, and the final webhook response.

## User Review Required

> [!IMPORTANT]
> The Sink API requires bearer token authentication. We will use `{{ $env.NUXT_SITE_TOKEN }}` within the `Shorten Editor URL` node. Please verify that this environment variable is configured on the target n8n instance.

## Proposed Changes

### Workflows

We will modify three workflow files to insert the `Shorten Editor URL` node and adjust the downstream references to use the shortened link.

---

### [MODIFY] [Overhead-North.workflow.ts](file:///\\wsl.localhost/Ubuntu/home/user/Repositories/n8n-as-code/workflows/brokertricks/Overhead-North.workflow.ts)

- Add the `ShortenEditorUrl` node (HTTP Request) at position `[600, 176]`.
- Shift the positions of:
  - `BackupEditorUrl`: `[600, 176]` -> `[800, 176]`
  - `Ntfy`: `[800, 176]` -> `[1000, 176]`
  - `RespondToWebhook`: `[1000, 176]` -> `[1200, 176]`
- In `ShortenEditorUrl`, configure it to request `POST https://link.brokertricks.com/api/link/create` with Bearer auth using `{{ $env.NUXT_SITE_TOKEN }}` and JSON body `{"url": "{{ $json.editorUrl }}", "comment": "Editor URL for order_{{ $json.order_id }}"}`.
- Update `BackupEditorUrl`:
  - Change URL to `=https://api.surecart.com/v1/orders/{{ $("all images url builder").item.json.order_id }}` (using preceding node reference).
  - Change `photopea_editor_url` property in body to `{{ $json.shortLink }}`.
- Update `Ntfy`:
  - Change Actions value to use `{{ $("Shorten Editor URL").item.json.shortLink }}`.
- Update `RespondToWebhook`:
  - Change `editor_url` property in response body to `{{ $('Shorten Editor URL').item.json.shortLink }}`.
- Update `defineRouting()`:
  - Route `this.AllImagesUrlBuilder.out(0).to(this.ShortenEditorUrl.in(0));`
  - Route `this.ShortenEditorUrl.out(0).to(this.BackupEditorUrl.in(0));`
